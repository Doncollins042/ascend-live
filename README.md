# ASCEND - Global Opportunities for Nigerian Talent

> Verified remote jobs and fully funded scholarships for Nigerians, plus tools to draft CVs, essays and cover letters tailored to each opportunity.

## Features
- Curated, verified remote job listings
- Fully funded scholarship directory
- AI-assisted CV, essay and cover letter drafting per opportunity

## Tech
HTML, CSS, JavaScript (`index.html` + `app.js`)

## Run

Open `index.html` in any browser, or deploy the folder to Netlify, Vercel or GitHub Pages.
